# 叙帧功能任务卡

这是可单独领取、分配到不同开发者并通过 PR 验收的功能点清单。整体目标与验收场景见 [生产平台功能规格](production-platform-spec.md)；迭代顺序、容量假设与关键路径见 [执行计划](execution-plan.md)。

## 领取规则

- 每张卡仅有一个主负责人；接口/API 与前端可以由不同负责人拆成关联子卡。
- 任务卡未满足依赖时不得提前实现会造成返工的 schema 或页面状态。
- 同一迭代只由一个负责人推进数据库 migration head；其他分支提交模型/API 变更但不擅自重排迁移。
- 每张卡完成后补负责人、分支/PR、实现提交、迁移号、验收证据、遗留项和后继卡；通过验收后才改状态为完成。
- 每张卡使用一个聚焦 Angular 中文提交；不要把多个无依赖功能点打包成大 PR。
