# 叙帧生产平台功能规格

## 目标

叙帧需要把小说、成品剧本、商品素材或创作构想转化为可审核、可恢复、可继续编辑的视频项目。AI 负责分析、规划和产出候选；创作者负责设定边界、审核、修改和决定是否进入下一阶段。画布用于观察和控制 AI 已规划的执行图，不要求用户手工搭图后才能生产。

完整交付包括可预览的成片，以及能够继续编辑的时间线项目。所有内容、媒体和决定都必须有版本、来源和输入快照。

## 创作维度

项目不能再用一个 `creation_mode` 同时表达输入来源、叙事形式和媒体生成路径。目标模型拆成三个独立维度：

| 维度 | 选项 | 说明 |
|---|---|---|
| 内容来源 `source_kind` | AI 原创小说、已有小说、成品剧本、商品素材、创意简报 | 决定导入、权利声明、锁版和分析步骤 |
| 叙事形式 `content_mode` | 剧情演绎、旁白/解说、广告短片 | 决定结构化剧本、对白/旁白、商品事实及审查规则 |
| 视频路径 `video_mode` | 分镜图生视频、参考图生视频 | 决定媒体任务输入；多宫格是分镜出图选项，不是第三种视频路径 |

每个项目可选是否需要 TTS、背景音乐、字幕、内部成片合成和可编辑工程导出。模型能力不满足所选路径时，系统在生成前给出明确替代方案或阻止原因，不生成虚假成功结果。

## 用户完整流程

1. **创建项目与来源登记**：选择来源、叙事形式、画幅、目标时长、语言、目标平台、权利状态和模型数据处理授权。导入 TXT/MD、结构化剧本或商品图片/视频；解析结果先预览再确认。
2. **内容分析与生产计划**：Agent 产出内容摘要、章节/场次映射、目标集数、时长预算、制作假设、风险和待确认事项。计划作为版本化候选，创作者可以逐项修改或退回。
3. **来源锁版**：建立不可变来源版本，记录章节/场景范围、内容哈希、文件哈希、来源位置、授权状态及上游版本。来源变更产生新版本，并将受影响的后续产物标为过期。
4. **分集规划**：AI 提出章节到分集映射、每集目标、冲突、转折、结尾钩子和保留事实；作者确认映射后形成分支版本。
5. **资产规划与登记**：识别角色、场景、道具和商品。每项资产包含稳定身份、别名、视觉约束、来源证据、版本化参考图及出场引用。AI 建议复用、新建、合并或衍生；人工确认后，资产才能作为下游生成锚点。
6. **剧本生产**：按叙事形式生成分集结构化剧本。剧情模式支持场景、动作、对白、角色关系与情绪；旁白模式支持旁白段落、画面意图与节奏；广告模式支持卖点、事实证据、展示场景、口播、行动号召和禁用宣称。每个段落保存来源引用及资产引用。
7. **分镜与连续性**：从已确认剧本生成镜头计划、时长、景别、机位、运动、提示词、前后镜连续性和资产引用。支持单镜和多宫格关键帧候选；多宫格审核后切分，保留原图和各镜历史。人可编辑、单镜重做或退回整组。
8. **媒体生成**：按镜头生成关键帧、视频片段和逐句对白/旁白音频。支持分镜图路径和参考图路径；每个任务冻结剧本、镜头、资产版本、参数、供应商能力和费用估算。候选经审阅后才成为已接受媒体。
9. **时间线剪辑**：以多轨时间线组织视频、对白/旁白、音乐、字幕、转场和片头片尾。支持排序、裁切、分割、替换、音量/淡入淡出、字幕时间码、预览、保存版本和撤销/恢复。所有编辑都保存为时间线版本，不覆盖源候选。
10. **合成与交付**：生成内部预览/母版并校验时长、画幅、音轨、字幕、文件完整性和来源快照。导出可继续编辑的工程文件；首个目标为中国大陆版剪映草稿，CapCut 兼容需单独验证。交付包包含视频、字幕、音频、素材清单、版本和校验信息。

## Agent 与人工控制

- Agent 根据目标和当前工件自动提出有序执行计划，并可自动运行已授权的无风险节点。
- 浏览器工作台、内置 Agent 和外部 Agent/API 共用同一应用服务、权限、成本上限和门禁；外部调用不能直接写数据库或绕过审核。
- 人工审核节点是显式状态；上游未通过门禁时不得启动依赖节点。
- 用户可暂停/恢复运行、重试单个失败节点、重做单个产物或下游分支，不重复提交已完成且输入未变的工作。
- 画布展示节点状态、依赖、任务、输入/输出摘要、参数、费用、错误和审阅决定；允许查看和编辑受支持的节点参数，并将编辑保存为新的运行输入版本。
- 画布是工作流的可观测控制面。关键路径应有表单、列表和时间线等结构化编辑界面，不能把业务操作只放在画布节点弹窗里。
- 任何 Agent 运行都不能绕开用户设定的成本上限、数据授权、权利门禁或人工确认策略。

## 后台任务与供应商

文本、图像、视频和 TTS 统一走后端 Provider Adapter；前端不接触密钥。Adapter 声明能力、参数范围、提交/轮询/取消方式、结果格式、用量和错误分类。协议兼容不视为真实能力验证。

任务模型至少包含 `Run → Batch → Task → Attempt`。持久化队列使用事务 outbox 或等价可靠投递；任务支持幂等、并发配额、排队/提交/运行/收集/待审/成功/失败/取消/过期、重试、取消、重启恢复和操作审计。视频供应商远端任务 ID 必须持久化；浏览器关闭不影响本地任务跟踪。

生成前记录估算成本，生成后记录供应商实际用量、币种、费率快照、失败/重试费用和差异。成本不可得时明确显示未知，不得记作零。

## 资产、候选与版本规则

- 源文件、结构化内容、资产、生成候选、时间线和交付物分开建模；关系引用稳定 ID 和版本。
- 已接受的版本不可被生成覆盖；重新生成会产生新候选。人工替换、恢复历史版本和资产合并都生成可审计事件。
- 候选保存完整来源快照和逐字段来源证据；用户修改与 AI 输出有明确区别。
- 上游修改通过依赖边计算影响范围；过期产物保留历史，但不能作为当前有效门禁输入。
- 媒体文件存储与元数据分离，以哈希校验完整性；上传和下载做大小、类型、路径、权限和安全检查。
- 项目支持可验证的归档、备份、恢复和版本迁移；导出包不包含 Provider 密钥或其他项目的私有资产。

## 状态和门禁

通用节点状态：`not_started → ready → running → needs_review → accepted`；可转 `failed`、`blocked`、`stale`、`cancelled`。仅显式允许的人工审阅决定可从 `needs_review` 进入 `accepted` 或 `rejected`。失败重试创建新 Attempt；新的输入快照创建新运行，不伪装为同一候选。

必需门禁：来源权利与版本；剧本结构和来源依据；资产身份与关键约束；分镜覆盖范围与连续性；媒体候选规格和上游引用；时间线轨道完整性；导出技术检查。每条门禁均有机器可验证条件、人工检查项、失败原因、修复入口和重新验收规则。

## 端到端验收场景

### 已有小说 → 成片

导入并预览章节 → 登记权利 → 锁定来源版本 → AI 分析/分集规划 → 审核资产 → 生成并审核剧本 → 生成并审核分镜 → 逐镜关键帧/视频 → 逐句配音或旁白 → 时间线编辑 → 预览/合成 → 导出 MP4 和可编辑工程。任一环节失败可恢复；单镜可重做；输入变更只使依赖产物过期。

### AI 原创小说 → 成片

创意简报 → 故事设定/大纲/角色 → 逐章生成 → 连续性审校 → 作者锁版 → 汇入与已有小说相同的视频生产链。作者可修订、恢复历史章节；未锁版正文不能进入改编制作。

### 商品/广告 → 成片

商品资料/图片/视频或创意 → 商品事实及证据 → 卖点和合规边界 → 广告脚本 → 商品视觉资产 → 参考图或分镜 → 视频/口播/TTS → 时间线 → 预览和交付。AI 不得凭空补充商品功效、参数、认证或价格；每条商品宣称要能回到素材证据或被标记为待核实。

### 故障恢复与人工控制

任务排队/运行时重启服务和关闭浏览器，任务状态与结果仍可恢复；重复请求不重复计费；重试生成新 Attempt；上游素材改变后旧候选显示过期且不能被下游接受；人工暂停的运行不会继续提交新供应商任务。

## 本阶段不承诺

第一版不承诺所有供应商 API 自动兼容、自动判断艺术质量、无需审阅的全自动发布、CapCut 与中国大陆版剪映互通、无限长视频实时编辑或云端重型渲染。每项依赖能力目录、技术校验和可重复验收后再开放。
